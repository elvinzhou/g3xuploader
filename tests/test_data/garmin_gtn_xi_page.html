Notes:

  • This software update is intended to be loaded on GTN 6XX Xi and 7XX Xi Navigators only.
  • G3X Touch (GDU 4XX)
     When installed alongside a G3X Touch system, G3X Touch software V8.91, or higher, is required. Smart Glide configuration is designed to be managed in the G3X Touch configuration menu. Smart Glide should remain disabled in GTN Xi configuration mode.
  • G3X (GDU 37X)
    The G3X requires V12.30, or higher, software to support Smart Glide. To ensure system compatibility, this setting should remain disabled until GDU software is updated.
  • G5 Electronic Flight Instrument (G5)
    The G5 requires V8.00, or higher, software to support Smart Glide. To ensure system compatibility, this setting should remain disabled until G5 software is updated.
