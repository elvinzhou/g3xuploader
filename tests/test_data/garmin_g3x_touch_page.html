Change History

Changes made from version 9.52 to 10.00:

  • Added support for GCO 14 carbon monoxide detector
  • Added support for GDL 90 RS-232 traffic data
  • Added heading bug auto sync mode
  • Added shortcut to set baro minimums by touching bottom half of altitude tape
  • Added configuration option to invert PFD lateral deviation when in reverse sensing region
  • Added configuration option to confirm calculated fuel quantity before every flight
  • Added additional configuration options for Vertical Power volts/amps gauges
  • Added support for custom calibration of magneto P-lead and electronic ignition RPM inputs

Changes made from version 9.51 to 9.52:

  • Improved NAV radio interface when using both ARINC 429 and RS-232
  • Improved turbine engine airframe time recording
  • Improved weather page display
